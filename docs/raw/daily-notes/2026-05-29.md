## Deployment

- Will be done locally in customer's system, possibly Windows computer.
- Must prioritize ease of startup, optimally, when Windows computer starts, the service should start as well.
- Should use local domain aliasing (invoicer.local -> localhost:8000)

## Invoice Creation Feature

- Required fields
	- Business information (the workshop itself)
	- Transaction date
	- Customer details
		- Name
		- Mobile number
	- Line items
		- Can only be physical item (supplies, auto parts, etc.)
	- Transaction summary (totals, tax, etc.)
	- Payment method?

## Dependencies

- Should keep frontend dependencies minimal as possible. Use blade views, eliminate Node.js / npm dependencies.
